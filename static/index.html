READY CHECK

完成设置前，请确认这些边界

费用由 API 服务决定

本工具不提供模型、额度或订阅权益。生成和编辑可能产生第三方费用。

先测试，再正式生成

保存配置后先测试 /models，再选择当前配置并生成低成本测试图。

只适合本机使用

服务默认监听 127.0.0.1，不要直接改成公网地址分享。

不要公开 API Key

不要把 Key 放入提示词、截图、仓库、JSON 或 Codex 对话。
